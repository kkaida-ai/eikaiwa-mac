# しゃべって英会話（Mac / Windows 用 AI英会話アプリ）

英語でフリートークすると、キャラクターの先生が返事と質問で会話を続け、間違いはその場で添削します。
会話をつくるAI・声（ずんだもん・リリー・Ken から選択）・音声認識はすべてパソコンの中で動き、会話や音声を外部に送りません。**無料**です。

- 紹介ページ: https://studio-kplus.ns-laboratory.com/eikaiwa/
- ダウンロード: [最新版の .dmg（Mac・Apple シリコン用）](https://github.com/kkaida-ai/eikaiwa-mac/releases/latest/download/shabette-eikaiwa-mac-arm64.dmg)（右側の **Releases** からも取得できます）

## 動作環境
- Mac: Apple シリコン（M1以降）、macOS 13 以降（Windows 版は準備中）
- メモリ 8GB（軽いAIモデル）または 16GB以上（標準のAIモデル）
- 初回の準備でAIや声のデータ（約 5〜6GB）を取得するため、インターネットと 10GB 以上の空き容量が必要です
- メモリ 8GB の Mac でも動く設定にしていますが、動作は 16GB 以上の方が安定します

## インストール
1. 上のリンクから `.dmg` をダウンロードして開き、「しゃべって英会話」を「アプリケーション」へドラッグ
2. アプリを起動する。「インターネットからダウンロードされたアプリケーションです」と出たら「開く」を押す（Apple の公証を受けたアプリです）
3. パソコンのメモリ容量（8GB／16GB以上）を選ぶ
4. 「はじめての準備」で「準備を始める」を押す。AI・声・音声認識のデータを自動で取得します（回線によって 10〜30 分ほど）
5. 準備が終われば、すぐに会話できます。2回目からは準備は要りません

## ずんだもんの声について（任意）
- アプリの「設定」→ ずんだもん →「ずんだもんの声を追加する」ボタンで、無料で追加できます（約1.9GBのダウンロード。Wi-Fi 推奨）。
- 追加しなくても、リリーと Ken の声で、すべての機能を使えます。
